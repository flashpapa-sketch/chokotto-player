========================================================
 ちょこっとplayer  version 1.1.2
 動画・音楽プレイヤー for Windows
========================================================

■ 概要

Windows 用の動画・音楽プレイヤーです。
Winamp クラシックスキン (.wsz) の読み込みと、
音楽CDの取り込みに対応しています。


■ version 1.1.2 の主な変更

  ・名前に「#」や「%25」を含む曲・動画が再生できなかった不具合を直しました
  ・曲のファイルを窓に落とすと、プレイヤーの画面が消えてしまう不具合を直しました
  ・音楽CDの曲名に記号などが入っていても、正しく文字として表示するようにしました
  ・壊れた Winamp スキン（.wsz）を読み込んだときに固まらないようにしました
  ・画面がインターネット上のものを読み込まないよう、守りを固めました
  ・土台の Electron を 43.8.3 に更新しました（安全性の修正を含みます）


■ version 1.1.1 の主な変更

  ・標準スキンを新しくしました（シグナル・オレンジ）
  ・見た目を 20 種類から選べます（オプション →「見た目」）
  ・選んだ見た目は、プレイリスト・イコライザ・CD取り込み・ヘルプの窓にも反映されます
  ・アプリのアイコンを新しくしました
  ・本体の大きさと部品の位置を Winamp 2.x と同じ 275×116 に揃えました
    （Winamp スキンに切り替えても窓の大きさは変わりません）
  ・シャッフルとリピートのボタンを本体に付けました
  ・書体をアプリに同梱しました（どの PC でも同じ見た目になります）
    Zen Kaku Gothic New / Zen Maru Gothic / Zen Old Mincho /
    Dela Gothic One / DotGothic16 / Anton / Bebas Neue / Orbitron / Space Mono
    いずれも SIL Open Font License 1.1（ライセンス文は resources の中の
    app.asar/public/fonts に同梱）
  ・スキンを後から足せるようになりました（下の「スキンの追加」）
  ・本体にプレイリストとイコライザのボタンを付けました
  ・曲の長さと、ハイレゾのときの「HI-RES」表示を出すようにしました
  ・Winamp スキン（.wsz）は、これまでどおり読み込めます


■ スキンの追加

  オプション →「見た目」→「スキンのフォルダを開く」で開くフォルダ
  （ちょこっとplayer.exe と同じ場所の skins）に、次の形で置きます。

      skins\好きな名前\main.css      本体の見た目（必須）
      skins\好きな名前\options.css   オプション窓の見た目（任意）
      skins\好きな名前\skin.json     {"name": "一覧に出す名前"}（任意）

  ・フォルダ名は半角英数字と - _ だけにしてください
  ・CSS は body[data-theme="plugin"] から書き始めます
    （例: body[data-theme="plugin"] { --accent: #ff0000; }）
  ・同梱の 15 種類は、そのまま真似できる見本です
  ・ネットの画像やフォントは読み込みません（外部へ通信しないため）
  ・入れたあと、オプション窓を開き直すと一覧に出ます


■ version 1.1.0 の主な変更

  ・ALAC（Apple Lossless）の M4A を再生できるようになりました
  ・曲名欄に、タグの「アーティスト - 曲名」を表示します
  ・タグの無い曲の曲名を、ネットで補えるようになりました
    （既定はオフ。詳しくは「曲名の表示」を参照）
  ・画面に音声の形式（例: FLAC 24/96）を表示します
  ・「ハイレゾ優先」の切り替えが、再生中の曲にすぐ反映されます
  ・オプションの設定が、次回起動時にも残るようになりました
  ・F1 キーで、バージョン情報と「困ったとき」を開けます
  ・再生できないとき、その理由を表示します
  ・イコライザやプレイリストを開いたまま本体を閉じると、
    終了できなくなる不具合を直しました

■ 【最初にお読みください】起動時の警告について
========================================================

初回の起動時、Windows が青い画面で

    「Windows によって PC が保護されました」

と表示することがあります。これは正常です。
ウイルスが見つかったという意味ではありません。


● なぜ出るのか

  Windows は、世の中でまだダウンロード数の少ない
  新しいソフトに対して、中身に関係なく警告を出します
  (SmartScreen という仕組みです)。

  この警告を出さないようにするには、開発者が
  年数万円の証明書を購入する必要があります。
  個人が作った無償のソフトでは、まず表示されます。


● 起動する方法

  1. 青い画面の中の「詳細情報」をクリックします
     （小さい文字のリンクです）

  2. 下に「実行」ボタンが出ますので、それを押します

  これで起動します。2回目以降は表示されません。


● ご自身で安全性を確認したい場合

  同梱の THIRD-PARTY-NOTICES.txt に、本ソフトが
  使用している部品をすべて記載しています。

  また、ファイルを VirusTotal (無料・ブラウザで使えます)
  にアップロードすると、60社以上のウイルス対策ソフトで
  一括検査できます。

      https://www.virustotal.com/

● 【重要】CD取り込みが動かない場合
========================================================

  音楽の再生は正常なのに、「音楽CDから取り込む」だけが
  動かない場合、ウイルス対策ソフトが原因です。

  症状:
    ・CD を入れても「音楽CDが見つかりません」と出る
    ・メニューは開くが、取り込みが始まらない


  ● 原因

    CD取り込みには ckcd.exe という補助プログラムを
    使っています。これがウイルス対策ソフトに
    隔離されている可能性があります。

    音楽CDには通常のファイルが存在しません。中身は
    音声データが並んでいるだけなので、取り出すには
    ドライブへ直接命令を出す必要があります。

    この「ディスクへ直接アクセスする」動作が、
    ランサムウェア等と形の上で区別がつかないため、
    一部のソフトが機械学習による推定で警告を出します。

    作者による確認 (VirusTotal・2026年8月時点):

        71社中 8社が反応
        うち Microsoft Defender を含む

        8件すべてが「機械学習による推定検知」であり、
        既知のウイルスとの一致ではありません。

    ckcd.exe は読み取り専用でのみ動作し、ディスクへの
    書き込みは一切行いません。
    処理内容は「目次の読み取り」と「音声の読み取り」の
    2種類の命令だけです。


  ● 対処方法

    お使いのウイルス対策ソフトの「除外設定」に、
    インストール先フォルダを追加してください。

      インストーラー版の既定の場所:
        C:\Users\(ユーザー名)\AppData\Local\Programs\
                                    ちょこっとplayer

      インストール不要版:
        展開したフォルダ

    Windows Defender の場合:
      設定 → プライバシーとセキュリティ
      → Windows セキュリティ
      → ウイルスと脅威の防止
      → 設定の管理 → 除外の追加または削除
      → 除外を追加する → フォルダー

    隔離済みの場合は、除外を追加したうえで
    「隔離された脅威」から復元するか、
    本ソフトを再インストールしてください。


  ● 除外設定をしたくない場合

    CD取り込み以外の機能 (動画・音楽の再生、
    プレイリスト、イコライザ、スキン) は
    除外設定なしで正常に動作します。

    CD の取り込みには、他の専用ソフトを
    ご利用ください。


  ● 作者より

    この警告を出なくするには、コード署名証明書
    (年額数万円) が必要です。無償配布のソフトでは
    費用を回収できないため、対応しておりません。

    ご自身で安全性を確認されたい場合は、前述の
    VirusTotal で検査してください。
    検知名に「ml」「AI」「confidence」「susgen」等が
    含まれる場合、それは推定による判定です。

■ 動作環境

  OS      : Windows 10 / 11 (64bit)
  メモリ  : 4GB 以上を推奨
  ディスク: 300MB 程度の空き

  音楽CDの取り込みには、光学ドライブが必要です。


■ 収録ファイル

  chokotto-player-1.1.2-setup.exe
      インストーラー版

  chokotto-player-1.1.2-portable.zip
      インストール不要版（展開してすぐ使える版）

  README.txt                このファイル
  EULA.txt                  使用許諾契約書
  THIRD-PARTY-NOTICES.txt   使用しているソフトウェアの権利表示


■ どちらを使うか

  ・インストーラー版
      通常はこちらを使ってください。
      デスクトップとスタートメニューにショートカットが
      できます。

  ・インストール不要版
      USB メモリなどに入れて持ち運べます。

      【展開のしかた】
        1. ZIP を右クリック →「すべて展開」を選びます
        2.「ちょこっとplayer 1.1.2」というフォルダが
           1つできます
        3. その中の「ちょこっとplayer.exe」を実行します

      ※ EXE だけを取り出しても動きません。
         同じ場所にある resources フォルダや DLL が必要です。
         フォルダごと移動・コピーしてください。


■ 対応フォーマット

  すべて実際に再生テストを行って確認したものだけを
  掲載しています。

  動画: MP4 / M4V / WebM / MKV / MOV
  音楽: MP3 / FLAC / WAV / AAC / M4A（AAC・ALAC）/ OGG /
        Opus / MKA / WebA

  ※ ALAC は再生の前に一時的な形式へ変換します。
     開いてから鳴り始めるまで、5分の曲で数秒〜10秒ほど
     かかります（状態欄に「変換 45%」のように出ます）。

  【対応していない形式】
    AVI / FLV / WMV / AIFF
      これらは再生できません。描画エンジンが
      対応していないためです。
      MP4 などに変換してからご利用ください。

  ※ 同じ MP4 でも、中に入っている映像・音声の
     コーデックによっては再生できないことがあります。


■ 音楽CDの取り込み

  「ファイル」→「音楽CDから取り込む…」で開きます。

  1. CD を入れると自動で曲目が表示されます
  2. 「曲名取得」を押すと、曲名・アーティスト名・
     アルバム名を取得します
  3. 保存する形式を選びます
  4. 「取り込む」を押し、保存先を選びます


  ● 選べる形式（CD1枚 39分ぶんの目安）

      FLAC 可逆圧縮           約 250MB
      MP3 320kbps 固定        約  92MB
      MP3 高音質 可変 (V0)    約  72MB
      MP3 標準 可変 (V2)      約  57MB
      MP3 192kbps 固定        約  56MB
      MP3 128kbps 固定        約  37MB
      WAV 無変換              約 400MB

    FLAC は音質を一切落とさずに容量を減らせます。
    MP3 は容量が小さく、他の機器でも再生しやすい形式です。

    曲名・アーティスト名・アルバム名・トラック番号は、
    ファイルのタグに書き込まれます。


  ● 曲名の取得について

    音楽CDには曲名が入っていません。入っているのは
    各曲の開始位置だけです。

    そこで「曲名取得」を押すと、曲の配置から計算した
    識別子を MusicBrainz という音楽データベースへ
    送って照会します。

      ・送るのはこの識別子だけです
      ・氏名やメールアドレスは一切送信しません
      ・押さなければ通信は発生しません

    データベースに登録のないディスクでは取得できません。
    その場合も Track01 … の連番で取り込めます。


  ● 取り込みにかかる時間

    お使いのドライブの速度によりますが、実測で
    CD1枚あたり 3〜5分程度です。


■ プレイリスト

  「ファイル」→「プレイリスト…」で開きます。

    ・曲をダブルクリックすると、その曲を再生します
    ・「追加」「削除」「全消去」で編集できます
    ・ウィンドウの大きさを変えられます
    ・Delete キーで削除、Enter キーで再生もできます


■ 曲名の表示

  曲名欄には、ファイルのタグにある「アーティスト - 曲名」を
  表示します。タグの無い曲はファイル名を表示します。
  プレイリストと Winamp スキンの曲名欄も同じです。


  ● ネットで曲名を補う（既定はオフ）

    「オプション」→「曲名」→「足りない曲名をネットで補う」を
    有効にすると、タグに曲名かアーティストが無い曲に限り、
    MusicBrainz（音楽データベース）に問い合わせて表示を補います。

      ・送るのはファイル名（またはタグの一部）だけです
      ・有効な間は、該当する曲を開くたびに自動で問い合わせます
      ・ファイルのタグは書き換えません（表示を補うだけです）
      ・結果はメモリにだけ置き、終了時に消えます
      ・この設定は保存されず、起動するたびにオフに戻ります
      ・確かな候補が見つからないときは、元の表示のままです

    曲名にカーソルを合わせると、表示の出どころ
    （タグ / MusicBrainz）と、アルバム名・年を確認できます。


■ 高解像度・ハイレゾについて

  ・8K (7680x4320) の再生に対応しています。
    GPU のハードウェアデコードを有効にしてあります。

    ただし滑らかに再生できるかは、動画のコーデックと
    お使いの GPU によります。
    8K/12K の映像は HEVC・AV1・VP9 で収録されたものを
    推奨します。H.264 の 8K はハードウェアデコードが
    効かず、CPU 負荷が非常に高くなります。

  ・ハイレゾ音源 (FLAC 24bit 96kHz / 192kHz など) の
    再生に対応しています。

    【重要】
    画面のスペクトラム表示は、音声を解析経路に通すため
    通常 48kHz に変換されます。
    原音のサンプリングレートのまま出力したい場合は、
    「オプション」→「音質」→「ハイレゾ優先」を
    有効にしてください。
    （スペクトラム表示は止まります）
    切り替えは再生中の曲にもすぐ反映されます。
    有効な間は、音量の上限が 100% になります。

  ・画面下段に音声の形式（例: FLAC 24/96）を表示します。
    ハイレゾは琥珀色、再生できない形式は赤で表示します。
    形式にカーソルを合わせると、出力の状態を説明します。


■ 履歴を残さない設計

  本ソフトウェアは、再生したファイルの履歴や
  キャッシュをパソコンに残しません。

  ・動作中に必要となる一時データは一時フォルダに隔離し、
    終了時に削除します。
  ・万一削除できなかった場合も、次回起動時に必ず掃除します。
  ・Windows の「最近使った項目」にも追加しません。
  ・ALAC を再生するときに作る変換済みの音声も、この一時
    フォルダに置き、終了時に削除します。ファイル名は
    無作為な文字列で、曲名は残りません。

  設定 (スキン・表示倍率・オプション) だけは、EXE と同じ場所の
  ck-settings.json に保存されます。
  「ネットで曲名を補う」の設定は保存しません。
  このファイルを削除すれば設定は初期化されます。


■ 基本の使い方

  1. ウィンドウ左上の「ファイル」にカーソルを合わせると
     メニューが出ます。次の操作がすべてここから行えます。

       ファイルを開く…                    Ctrl+O
       再生 / 一時停止 / 停止 / 前の曲 / 次の曲
       Winamp スキンを読み込む… / 標準スキンに戻す
       表示倍率 → 等倍 (275x116) / 1.5倍 / 2倍
       音楽CDから取り込む…
       プレイリスト…
       イコライザ…
       オプション…
       終了                               Alt+F4

  2. 「ファイルを開く…」で再生したいファイルを選びます。
     複数選択するとプレイリストになります。
  3. 下段のボタンで 前の曲 / 再生 / 一時停止 / 停止 /
     次の曲 を操作します。

  ・ボタンが小さいと感じる場合は「表示倍率」を
    1.5倍 または 2倍 に変更してください。

  ・動画ファイルを再生すると、映像は別ウィンドウで開きます。
    映像部分をダブルクリックすると全画面になります。
    全画面は Esc で解除、スペースキーで再生・一時停止できます。

  ・ファイルをこのアプリの EXE にドラッグしても再生できます。


■ オプション

  「ファイル」→「オプション…」で次の設定ができます。

    音量 (0〜200%) / 再生速度 (0.5〜2.0倍) /
    繰り返し / シャッフル / ハイレゾ優先 /
    ネットで曲名を補う

  ※ 音量は 100% が原音です。音源が小さいときは
     200% まで増幅できます。


■ イコライザ

  「ファイル」→「イコライザ…」で開きます。

    プリアンプ ＋ 10バンド
    (70 / 180 / 320 / 600 / 1k / 3k / 6k / 12k / 14k / 16k Hz)
    各 -12dB 〜 +12dB

  プリセット:
    フラット / ロック / ポップ / ジャズ / クラシック /
    低音強調 / 高音強調 / ボーカル

  左上の OFF ボタンで有効・無効を切り替えます。
  動画の音声にも同じように効きます。

  ※「ハイレゾ優先」を有効にしているとイコライザは
     働きません。原音をそのまま出力するためです。


■ Winamp スキンの使い方

  「ファイル」→「スキンを読み込む…」で .wsz ファイルを
  選びます。
  選んだスキンは記憶され、次回起動時に自動で適用されます。
  「標準スキンに戻す」で元に戻せます。

  対応しているスキンの部品:
    本体背景 / タイトルバー / 操作ボタン / シークバー /
    音量つまみ / 再生状態ランプ / 時間表示 / 曲名 /
    シャッフル・リピートボタン / 変形ウィンドウ (region.txt)

  未対応の部品:
    バランス / モノ・ステレオ表示

  ※ EQ ボタン・PL ボタンは動作しますが、開くのは
     本ソフト独自の画面です。スキンの eqmain.bmp や
     pledit.bmp による見た目の変更には未対応です。

  ※ 未対応部品を含むスキンも読み込めます。
     対応している部分だけが反映されます。

  ※ スキン内の文字表示はアルファベットと数字のみ対応です。
     日本語のファイル名は自動的に通常フォントで表示されます。


■ アンインストール

  インストーラー版:
    Windows の「設定」→「アプリ」から削除してください。

  インストール不要版:
    展開したフォルダごと削除してください。

  どちらの場合も、EXE と同じ場所に
  ck-settings.json があれば削除してください。
  これ以外にパソコンへ残るものはありません。
